# Digital AIM · Local business bot demo

Open index.html directly, or run `python3 -m http.server 8080 --directory /workspace/demo-bot` and visit http://localhost:8080.

This is a fictional sample business, not affiliated with similarly named real companies. The exact name was checked with a public web search on November 11, 2026; that search did not surface an exact Lewisville-area match. This is not a trademark clearance.

No backend, API keys, cookies, analytics, storage, network calls, appointments, dispatch, SMS, email or review posting. Only the owner contact mailto link can open the visitor's email app; it does not send anything. Refresh clears chat contents. All contact information entered into chat should be fictional. Shop phone uses the reserved 555-01xx range, and shop email is under example.com. All shop policies, hours and fees are examples. The $89 diagnostic fee is a placeholder. Offer pricing is $497 setup + $197/month; actual integrations/provider fees need agreement.

Urgent messages provide limited safety guidance and flag a sample lead; this is not a real emergency service. Preferred visit times are requests, not real calendar availability. Rule-based matching cannot interpret every phrasing. US phone-format validation and US five-digit ZIP/address shape validation do not verify real identities, numbers or coverage. No financing eligibility or warranty promise is made.

Website: index.html, style.css, app.js. All assets are local CSS; works without an internet connection. No dependencies required to use the site. Test evidence is in screens/ and test-results.json. Do not publish without the owner's explicit approval.
